    function getJobId(): string | undefined {

      const jobIdIndex = args.indexOf('--job-id')

      return process.env.JOB_ID

    **Step 2: Fix SQL column whitelist in `src/lib/db.ts`**

    In `updateJobStatus` function, add column whitelist validation before the SQL construction. Per D-15:

    ```typescript
    const ALLOWED_COLUMNS = new Set(['started_at', 'completed_at', 'error_message', 'sandbox_pid'])

    export function updateJobStatus(id: string, runStatus: string, extra?: Record<string, any>): void {
      const sets = ['run_status = ?']
      const values: any[] = [runStatus]

      if (extra) {
        for (const [k, v] of Object.entries(extra)) {
          if (k === 'budget') {
            sets.push('budget_json = ?')
            values.push(JSON.stringify(v))
          } else if (k === 'sandbox_pid' || k === 'started_at' || k === 'completed_at' || k === 'error_message') {
            // Whitelisted columns only
            sets.push(`${k} = ?`)
            values.push(v)
          } else if (!ALLOWED_COLUMNS.has(k)) {
            throw new Error(`Invalid column in updateJobStatus: ${k}`)
          }
        }
      }

      values.push(id)
      getDb().prepare(`UPDATE jobs SET ${sets.join(', ')} WHERE id = ?`).run(...values)
    }
    ```

    Note: budget is special-mapped to budget_json column. sandbox_pid is in ALLOWED_COLUMNS and also checked explicitly for clarity. The throw ensures no unknown keys slip through.

| sandbox-executor -> child process | 环境变量从父进程传到子进程，子进程运行 Agent 代码 |

| API client -> POST /api/jobs | 请求体是完全不可信的外部输入 (handled in Plan 02) |
| db.ts caller -> SQL | extra 参数的 key 被插入 SQL 列名位置 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | E (Elevation) | sandbox-executor.ts | mitigate | 环境变量白名单 (D-06/D-07)，不展开 process.env，子进程只能访问白名单中的 10 个变量 |
| T-01-02 | S (Spoofing) | agent-runner.ts | mitigate | JSON.parse try/catch (D-16)，畸形 LLM 响应不崩溃，记录错误继续运行 |
| T-01-03 | T (Tampering) | db.ts updateJobStatus | mitigate | 列名白名单 (D-15)，非白名单 key 直接 throw，防止 SQL 注入 |
